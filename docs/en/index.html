Keep the ChatGPT or Codex conversation that needs you in view

GPT Needs You is a local desktop companion for attention requests. It keeps the conversation title and requested action in a floating card while you type, and stacks alerts in arrival order.

Download macOS + Windows ZIP (v0.3.3)Release notesSource and full guide

What the desktop alert does

  • Keeps the conversation title and requested action visible until you dismiss the card.
  • Leaves keyboard input with the app you are using; typing does not dismiss the alert.
  • Stacks simultaneous alerts so earlier requests remain visible.
  • Opens the provided chat or authentication page while keeping the alert available.
  • Lets you pause new alerts for 24 hours and customize sound.

Install in three steps

  1. Download the ZIP package and extract it. The package contains the plugin and both operating-system companions.
  2. ChatGPT desktop: add the marketplace in Terminal with codex plugin marketplace add delight0517-art/chatgpt-attention-alert, restart ChatGPT desktop, then check Plugins for ChatGPT Attention Alert. Local plugins may install automatically and may not show an install card. Codex CLI: add the marketplace, then run codex plugin add chatgpt-attention-alert@chatgpt-attention-alert-local.
  3. Install the desktop companion: on macOS, run ./install-macos.sh from the extracted folder. On Windows PowerShell, run Set-ExecutionPolicy -Scope Process Bypass, then .\Install-Windows.ps1.

Both the plugin and the macOS or Windows companion are required. ChatGPT in a web browser alone cannot display native desktop alerts. See the complete installation guide if a step is unclear.

Privacy and recommendations

The companion displays the title and request supplied by the agent. Recommendation matching, when enabled, uses local rules without an AI request; alert text is not saved or sent for recommendations. Authentication alerts are excluded. Read the privacy and optional website analytics notice.

Common questions

Does installing the plugin install the desktop alert too?

No. Install the plugin and run the companion installer for your operating system.

Is this in the official ChatGPT public plugin directory?

No. This is a GitHub-hosted open-source package and local marketplace source; it is not an OpenAI directory listing.
