ChatGPTやCodexで確認が必要な会話を見逃さない

GPT Needs Youは、ユーザーの確認を待つ会話タイトルと依頼内容をデスクトップに表示するローカル通知ツールです。入力中もカードが残り、複数の通知は届いた順に重ねて表示されます。

macOS・Windows ZIPをダウンロード (v0.3.3)更新情報ソースと詳しい手順

デスクトップ通知の機能

  • 確認するまで会話タイトルと依頼内容を表示します。
  • 入力中も通知は消えず、キーボード操作を妨げません。
  • 同時に届いた通知を順番に表示します。
  • 指定された会話や認証ページを開いても通知カードは残ります。
  • 新しい通知を24時間停止したり、通知音を変更したりできます。

3ステップでインストール

  1. ZIPパッケージをダウンロードして展開します。プラグインとmacOS・Windows用のインストーラーが含まれています。
  2. ChatGPTデスクトップ: ターミナルで codex plugin marketplace add delight0517-art/chatgpt-attention-alert を実行し、アプリを再起動してPluginsで「ChatGPT Attention Alert」を確認します。ローカルプラグインは自動で追加され、インストールカードが表示されない場合があります。Codex CLI: 同じマーケットプレイスを追加し、codex plugin add chatgpt-attention-alert@chatgpt-attention-alert-local を実行します。
  3. デスクトップ通知のインストール: macOSでは展開したフォルダで ./install-macos.sh を実行します。Windows PowerShellでは Set-ExecutionPolicy -Scope Process Bypass の後に .\Install-Windows.ps1 を実行します。

プラグインとOS用通知アプリの両方が必要です。ChatGPTのブラウザー版だけではネイティブ通知を表示できません。詳しくはインストールガイドをご覧ください。

プライバシーとおすすめ表示

おすすめ機能は端末内の固定ルールで判定し、AIへのリクエストや通知本文の保存・送信を行いません。認証通知は対象外です。プライバシーと任意のサイト統計について。

よくある質問

プラグインを入れれば通知も使えますか？

いいえ。プラグインに加えて、macOSまたはWindows用の通知アプリもインストールしてください。

OpenAIの公式プラグイン一覧に掲載されていますか？

いいえ。GitHubで配布するオープンソースパッケージで、OpenAIの公式一覧への掲載を意味しません。
