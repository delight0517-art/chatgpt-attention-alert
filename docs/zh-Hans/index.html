不要错过需要你处理的 ChatGPT 或 Codex 对话

GPT Needs You 是一款本地桌面提醒工具，会显示需要你确认的对话标题和操作内容。你输入文字时提醒仍会保留，多个提醒按到达顺序错开显示。

下载 macOS + Windows ZIP (v0.3.3)版本更新源代码和完整指南

桌面提醒功能

  • 在你确认前持续显示对话标题和需要执行的操作。
  • 输入文字不会关闭提醒，也不会抢走键盘焦点。
  • 多个提醒按顺序错开放置，方便查看较早的请求。
  • 打开指定对话或认证网页后，提醒卡片仍保留。
  • 可暂停新提醒24小时，也可以自定义提醒声音。

三步安装

  1. 下载 ZIP 安装包并解压。软件包包含插件及 macOS、Windows 安装程序。
  2. ChatGPT 桌面版：在终端运行 codex plugin marketplace add delight0517-art/chatgpt-attention-alert，重启 ChatGPT 桌面版，然后在 Plugins 中查找“ChatGPT Attention Alert”。本地插件可能会自动安装，因此不一定显示安装卡片。Codex CLI：添加同一 Marketplace 后运行 codex plugin add chatgpt-attention-alert@chatgpt-attention-alert-local。
  3. 安装桌面提醒程序：macOS 在解压后的文件夹中运行 ./install-macos.sh。Windows PowerShell 先运行 Set-ExecutionPolicy -Scope Process Bypass，再运行 .\Install-Windows.ps1。

插件和操作系统的桌面程序都需要安装。仅使用 ChatGPT 网页版无法显示系统桌面提醒。请查看完整安装指南。

隐私与推荐内容

推荐内容使用设备本地规则匹配，不调用 AI，也不会为推荐保存或发送提醒原文。认证提醒不会显示推荐。请阅读隐私和可选网站统计说明。

常见问题

安装插件后，桌面提醒就能用了吗？

还不行。还需要为你的操作系统运行 macOS 或 Windows 桌面程序安装脚本。

这是 OpenAI 官方插件目录中的插件吗？

不是。这是通过 GitHub 发布的开源软件和本地 Marketplace，不代表已列入 OpenAI 官方目录。
